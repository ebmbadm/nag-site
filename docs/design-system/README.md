# Дизайн-система NAG · NOVIK

Новая визуальная система для сайта, печатных документов и программы управления процессором.
Владелец утвердил её 8 ноября 2026 года как основу редизайна. В код сайта она ещё не перенесена:
`app/globals.css` и `components/ds/` пока на старой системе (Oswald, тёплая бумага, моно-подписи).

## Где смотреть

- Дизайн-система в Claude Design: https://claude.ai/artifact/GAugEKeXiRAG871M1PMqqw
- Холст с направлениями и макетами: https://claude.ai/artifact/3wFKUMmKfAFEHRJVkbufKS

Оба артефакта приватные; доступ другим людям — через меню Share.

## Что в папке

| Путь | Что |
|---|---|
| `system/README.md` | брендбук: тексты, цвет, шрифт, сетка, фото, иконки, состояния, запреты |
| `system/1-site.md`, `2-print.md`, `3-software.md` | правила для сайта, печати и программы |
| `system/tokens.json` | токены: две темы, шкала шрифта в трёх плотностях, отступы, скругления, размеры, тень |
| `system/components/` | 18 компонентов: `bundle.js` (React, `window.Nag`), `bundle.css`, `index.d.ts`, у каждого `README.md` и `preview.html` |
| `system/assets/` | описание логотипов (сами файлы — `public/brand/`) и эталонные фото лицевых панелей |
| `system/design-system.json` | индекс артефакта: id загруженных файлов |
| `mockups/` | исходники досок холста (`.dc.html`) и `canvas.json` |

Файлы из `system/` и `mockups/` — копия артефактов на момент коммита. Картинки в них ссылаются на
`/_blob/<id>` и открываются только внутри артефакта.

## Решения

- Характер — спокойный инженерный каталог. Фон чисто белый, тёплая бумага отклонена.
- Тёмная тема — для программы и одной тёмной вставки на сайте.
- Красный `#D41406` — только главное действие и тревога.
- Анимация лёгкая: отклик на наведение, плавные окна и аккордеоны, мягкое появление разделов при прокрутке (решение владельца 08.11.2026).
- Один шрифт — Golos Text, обычный регистр. Без Oswald, без моноширинного, без капса-надзаголовков.
- Скругления 4–8 px, шаг отступов 4 px, плотность сбалансированная.
- NOVIK — та же система, нюанс только в цвете слова.
- Из макетов убраны шаблоны, которые выдают ИИ-дизайн (по списку Impeccable, pbakaus/impeccable):
  - надзаголовки над заголовками;
  - номера разделов 01/02 на сайте;
  - ряд крупных цифр под первым экраном;
  - сетки одинаковых карточек;
  - серые плашки под фото.
- Каталог — список строк, рэковые приборы одной ширины на белом.
- Программа: одна таблица каналов по пути сигнала и редактор, где частотная характеристика видна всегда.

## Паспорт сайта

Сверено с `docs/pasport-sayta-novikamps.html`. Дизайн в разбор паспорта не входил, ограничения по
содержанию соблюдены:
- в макетах и брендбуке нет «российского производства», «от производителя», превосходных степеней
  без числа, «дизайна Gibson» и неподтверждённых «192 кГц / 32 бит» у D-8000;
- раздел «История» не тронут.

Расхождения, найденные по ходу и вынесенные на решение владельца:
- **Мощность QM-400.** Карточка сайта: 4 × 2400 Вт на 4 Ом, мост 2 × 4800 Вт. Руководство, изд. 1 · 08.2026: 4 × 2000 Вт и 2 × 3800 Вт.
- **Условия гарантии.** В макете гарантийного талона текста условий нет — нужен от NOVIK.
