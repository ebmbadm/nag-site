# Логотипы

- `nag-logo-onlight.png` — логотип NAG для светлого фона: знак чёрный, «N» и диагональ красные. Шапка сайта (высота 22 px), обложка мануала (26 px), гарантийный талон, программа в светлой теме (16 px).
- `nag-logo-mono-white.png` — белый вариант для тёмного фона: подвал, тёмная вставка сайта, программа в тёмной теме.
- `nag-mark-red.png` — знак без надписи, красный. Иконка вкладки и приложения.
- `nag-mark-white.png` — знак без надписи, белый, на тёмном фоне.

Логотип не перекрашивают, не обводят и не ставят на фото. Свободное поле вокруг — не меньше высоты буквы «N». Отдельного логотипа NOVIK в исходниках нет: в текстах NOVIK пишется словом, нюанс — цвет `novik`.
