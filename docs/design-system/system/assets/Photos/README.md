# Фото техники

Образцы обработки: лицевая панель вырезана по прибору, фон белый, без значков и надписей поверх.

- `qm400-front.jpg` — NAG QM-400, 2U, вид спереди с крышкой.
- `td40-front.jpg` — NAG TD40, 1U, строго спереди.
- `f8-front.jpg` — NAG F-8, 1U, вырезан из рекламного снимка без значков Wi-Fi и логотипов чипов.

В строке каталога все рэковые приборы ставятся одной ширины (`photo-rack`): QM-400 тогда выходит вдвое выше TD40, как в стойке.
