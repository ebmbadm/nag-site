# Breadcrumb

Путь до страницы товара: каталог, категория, модель.

## Что передать

- `items` — `{label, href}`; у последнего пункта `href` не нужен, он помечается `aria-current`.

## Правила

- 14 px, ссылки `ink-2`, разделитель «/» и текущий пункт `ink-3`. Только на карточке товара и в разделах каталога.
