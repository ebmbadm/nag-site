# Button

Кнопка называет действие; красная (`primary`) — одна на экран, для того, ради чего экран существует.

## Что передать

- `children` — глагол и результат: «Запросить счёт», «Записать в процессор», «Скачать PDF».
- `variant`: `primary` (заливка `accent`, текст `on-accent`), `secondary` (контур `line-control`, по умолчанию), `quiet` (подложка `surface`), `link` (подчёркнутый текст).
- `size`: `lg` 48 px на сайте, `md` 40 px для компактных мест, `sm` 32 px в программе.
- `icon`, `iconAfter` — имя иконки Lucide; `href` превращает кнопку в ссылку.

## Правила

- Вторая и третья кнопка рядом с красной — `secondary` или `quiet`, никогда не вторая красная.
- Не «Подробнее» и не «Нажмите здесь»: подпись говорит, что произойдёт.
- Недоступная кнопка — `disabled`: фон `surface`, текст `ink-3`; рядом объясните, почему.
