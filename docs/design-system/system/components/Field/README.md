# Field

Поле ввода с подписью сверху и подсказкой или ошибкой снизу.

## Что передать

- `label` — всегда видимая подпись, не placeholder.
- `help` — подсказка `ink-3`; `error` — заменяет подсказку, красит границу в `danger` и ставит `aria-invalid`.
- `multiline` и `rows` — многострочное поле.
- `size`: `lg` 48 px на сайте, `sm` 36 px в программе.
- Остальные свойства уходят в `<input>` или `<textarea>`: `type`, `value`, `onChange`, `name`.

## Правила

- Ошибка называет проблему и что сделать: «В адресе нет символа @. Проверьте и введите ещё раз».
- Фокус — граница 2 px цвета `ink`. Граница в покое — `line-control` (3:1).
