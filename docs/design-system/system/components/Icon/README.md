# Icon

Иконки Lucide с линией 1,75: 20 px на сайте, 16 px в программе, цвет текста рядом.

## Что передать

- `name` — одно из имён набора; `size`; `label` — если иконка несёт смысл без слова (тогда у неё `role="img"`).

## Правила

- Иконка стоит рядом со словом. Кнопка из одной иконки получает `aria-label`.
- В наборе только иконки, которые уже нужны сайту, документам и программе. Новые берутся из того же Lucide (на сайте — пакет `lucide-react`), с той же толщиной линии.
- Эмодзи и символы Юникода вместо иконок не используются. Исключение — знаки M и Ø на кнопках канала: это принятые обозначения на пультах.
