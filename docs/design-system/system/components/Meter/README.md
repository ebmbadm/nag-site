# Meter

Индикатор уровня канала: полоса и значение в дБ.

## Что передать

- `level` — уровень в дБ от полной шкалы, например −12.
- `muted` — канал без звука: пустая полоса и «без звука».
- `width` — длина полосы, по умолчанию 72 px; `showValue={false}` — без подписи.

## Правила

- До −10 дБ — `ok`, до −3 дБ — `warn`, выше — `danger` и слово «перегрузка» жирным.
- Пустая часть — `meter-track`. Цвет всегда сопровождается числом или словом.
