# Notice

Сообщение в тексте: примечание, предупреждение, ошибка. Одинаково на сайте, в мануале и в программе.

## Что передать

- `tone`: `info` (фон `surface`), `warn` (`warn-soft`, заголовок `warn`), `error` (`danger-soft`, заголовок `danger`, `role="alert"`).
- `title` — первое слово или фраза жирным: «Внимание.», «Примечание.», «Нет связи с процессором.».
- `children` — что делать.

## Правила

- Иконка и тон фона. Цветной полосы слева нет.
- Ошибка говорит, как её исправить.
