# ParamCell

Ячейка таблицы каналов: одно значение шага обработки, по клику открывает его редактор.

## Что передать

- `children` — значение по-русски: «4,20 мс», «30 Гц · LR», «2 полосы».
- `off` — шаг ничего не делает («Выкл.», «Норм.», «0,00 мс»): текст `ink-3`.
- `selected` и `onClick` — выбор ячейки.

## Правила

- Выбранная — `surface-raised` и кольцо 1,5 px цвета `ink`; строка с ней — фон `surface`.
- Столбцы таблицы — по пути сигнала: источник, усиление, задержка, полярность, ФВЧ, ФНЧ, эквалайзер, гейт или лимитер.
- Таблица собирается из `div` с CSS-сеткой и ролями `role="table"`, `row`, `cell`: так циклы шаблона не ломают разметку.
