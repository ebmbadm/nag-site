# ProductRow

Строка каталога: фото, модель, суть, ключевые цифры и цена справа.

## Что передать

- `name` — модель с брендом: «NAG QM-400».
- `image`, `imageAlt` — лицевая панель на белом; рэковые приборы — одной ширины `photo-rack`. Для модулей и ламповых голов — `boxed`: фото высотой 200 px.
- `summary` — суть в одной строке; `spec` — одна-две цифры через «·».
- `price` — готовая строка («199 900 ₽», «от 70 000 ₽»); без `price` строка покажет «По запросу».

## Правила

- Цифры — те же, что в карточке и в мануале.
- Строки идут списком с линиями `line`, не сеткой карточек.
