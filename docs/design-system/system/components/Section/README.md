# Section

Раздел страницы: заголовок с описанием слева (1 часть), содержимое справа (3 части), над ним линия `line-strong`.

## Что передать

- `title` — заголовок раздела (`site-section`); `description` — одна-две строки `ink-2`; `aside` — ссылка под описанием.
- `children` — содержимое: строки каталога, таблица характеристик, фото, документы.

## Правила

- Между разделами — `space-24`. На узком экране колонки встают друг под друга.
- Один и тот же макет на главной и в карточке товара: заголовок слева читается как оглавление.
