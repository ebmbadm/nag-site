# Segmented

Выбор одного из двух–шести вариантов, которые видны все сразу.

## Что передать

- `options` — `{value, label}`; `value` и `onChange` или `defaultValue`.
- `label` — видимая подпись; без неё — `ariaLabel`.
- `size`: `lg` или `sm` (программа).

## Правила

- Дорожка — `surface`, выбранный вариант — `surface-raised`, текст `ink` 500 и тень `shadow-raised`. Это единственная тень в системе.
- Подходит для режима усилителя (стерео, параллель, мост), источника выхода, полярности.
