# Select

Выпадающий список из нативного `<select>` со стрелкой Lucide `chevron-down`.

## Что передать

- `label`, `options` (строки или `{value, label}`), `value` и `onChange` или `defaultValue`.
- `help` — подсказка под полем; `size`: `lg` или `sm`.

## Правила

- Больше семи вариантов, которые важно видеть сразу, — не список, а `Segmented` или таблица.
