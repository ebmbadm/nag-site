# SpecTable

Таблица характеристик: подпись слева цветом `ink-2`, значение справа, табличные цифры.

## Что передать

- `rows` — `{label, value}` и `caption`, или `groups` — `{title, rows}` для нескольких групп.
- `density`: `site` (16 px), `print` (13 px, 9,5 pt — мануалы), `app` (14 px — программа).

## Правила

- Значения пишутся по-русски: «0,1 %», «−99 дБ», «483 × 463 × 88 мм», неразрывный пробел перед единицей.
- Значение в таблице сайта, мануала и программы одно и то же. Расхождение — повод остановиться и выяснить.
