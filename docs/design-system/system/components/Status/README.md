# Status

Состояние — точка и слово: наличие модели, связь с прибором, запись в процессор.

## Что передать

- `tone`: `ok`, `warn`, `danger`, `off` (полая точка, текст `ink-2`).
- `children` — слово или короткая фраза; `size="sm"` — 13 px для шапки программы.

## Правила

- Цвет никогда не стоит без слова: красный и зелёный различают не все.
- Не плашка с заливкой: точка 8 px и текст.
