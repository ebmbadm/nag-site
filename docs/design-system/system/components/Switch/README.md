# Switch

Переключатель для функции, которая включается сразу, без кнопки «Сохранить».

## Что передать

- `label`; `checked` и `onChange(on)` или `defaultChecked`.

## Правила

- Включённый — заливка `ink`, бегунок `bg`. Не красный и не зелёный: это состояние, а не статус.
- Работает как `role="switch"`, переключается пробелом и кликом.
