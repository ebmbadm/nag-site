# Tabs

Ссылки по разделам страницы или панели; текущая подчёркнута линией 2 px цвета `ink`.

## Что передать

- `items` — `{label, href, current}`; `label` — имя навигации для диктора.
- `density`: `site` (16 px) или `app` (14 px).

## Правила

- Текущий пункт — `ink` и подчёркивание, остальные — `ink-2`. Красным не выделяется.
