# Tag

Короткая техническая метка у модели: класс, высота, разъёмы.

## Что передать

- `children` — одно-три слова.

## Правила

- Контур `line-strong`, текст `ink-2` 13 px, `radius-sm`. Не кнопка и не фильтр: на метку не нажимают.
- Не больше четырёх меток подряд; остальное — в таблицу характеристик.
