# ToggleButton

Кнопка-переключатель 28 × 28 для программы: «Без звука» (M) и полярность (Ø) в строке канала.

## Что передать

- `pressed` — состояние; `onClick` — переключение.
- `tone`: `alarm` — включённая красная (`accent`), для «Без звука»; `ink` — включённая заливка `ink`, для полярности.
- `label` — обязательное имя для экранного диктора: «Без звука, выход 3».
- `children` — одна буква или знак: M, Ø.

## Правила

- Красный у включённой M — единственный красный в таблице каналов, кроме «перегрузки».
- Выключенная — контур `line-control`, без заливки.
