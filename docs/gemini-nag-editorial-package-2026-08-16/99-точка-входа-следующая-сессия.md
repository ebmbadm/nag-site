# Точка входа: NAG → внешняя редактура в Gemini

Дата фиксации: 16 августа 2026.

## Что подготовлено

В этой же папке лежит пакет для независимой проработки текстов действующего раздела NAG:

1. `00-Задача-для-Gemini-NAG.md` — постановка задачи, ограничения, мой пробный вариант и запрос на нестандартные ходы.
2. `01-исходная-выгрузка-TDS-TDH.md` — исходный массив по модулям и отзывам; только для анализа, не для публичного цитирования без проверки.
3. `02-краткий-анализ-Паспорта-сайта.md` — ранее полученный анализ и рекомендации по «Паспорту сайта».

## Что уже сделано локально и чего не сделано

- Gemini был открыт в отдельной вкладке и остановлен на форме входа в Google.
- Никакие файлы в Gemini **не загружались**, задача не отправлялась.
- Действующий сайт NAG не менялся в рамках подготовки пакета.
- «Ламповый бутик» не трогался.

## Следующий шаг после входа/оплаты Gemini

1. Войти в Gemini в своей учётной записи.
2. Прикрепить три файла `00`, `01`, `02` из этой папки.
3. Отправить сообщение:

> Выполни задачу из файла `00-Задача-для-Gemini-NAG.md`. Два остальных файла — исходные материалы и анализ. Не используй личную переписку и непроверенные отзывы как публичные цитаты. Нужны варианты текстов для существующей структуры главной NAG; «Ламповый бутик» не менять.

4. После ответа Gemini не переносить тексты в сайт автоматически: сначала сравнить варианты с подтверждёнными фактами владельца и показать их на локальном предпросмотре в существующей вёрстке NAG.

## Критерий хорошего результата

Не подменить повтор «100% тестирование» повтором «прогон». Первый экран, цифры и четыре карточки должны раскрывать разные смыслы: назначение, проверяемые факты, приёмку под нагрузкой, настройку входной платы, согласованное обслуживание и поддержку на объекте.
