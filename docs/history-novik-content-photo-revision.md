# История NOVIK: согласованные правки текста и фотографий

Статус: локальная фиксация требований перед редактированием страницы.
Дата: 2026-08-04

## Правки по годам

| Год | Согласованное содержание | Фото |
| --- | --- | --- |
| 1992 | Только SPETEL. NOVIK и RedBeaЯ в этот блок не включать. | Существующее фото оставить до отдельного решения. |
| 1993 | Одновременное появление NOVIK и RedBeaЯ. Для названия бренда использовать логотипное написание `RedBeaЯ`, как на усилителе. | Поставить MK120; текущий RedBear MK60 с колонкой убрать из этого места. |
| 1994 | MKE 120/60. | Нужна фотография MKE 120/60 без колонки; ожидается от второго компьютера. |
| 1995 | MKX 50 оставить. Ближе к концу текста добавить упоминание NOVIK N1202; точное место в абзаце не принципиально. | Оставить текущую фотографию MKX 50. |
| 1996 | N1202C / N602C — комбо-версия. | Нужна подходящая фотография; если лучшего варианта не будет, использовать одну из последних трёх фотографий N1202C. |
| 1997 | 602 как PA-усилитель; комбо-версию убрать. | Нужна фотография 602 PA. |
| 1999 | 1202 как PA-усилитель. | Нужна фотография 1202 PA. |
| 2000 | E12 — самый мощный усилитель линейки. | Нужна фотография E12. |

## Термины и модели

- 602 и 1202 — ламповые PA-усилители (оконечники).
- Последующая линейка: E1202, E202 и E12; модели отличаются количеством ламп
  и мощностью.
- В конце производства на 602 и 1202 начали наносить маркировку Black Fier;
  это не отдельная модель. Точное написание будет сверено по фотографии
  шильда.
- Есть исполнения 602 в светлом деревянном корпусе и с открытым расположением
  ламп. Их не выделять в самостоятельную линейку без отдельного решения.

## Резерв и ожидаемые материалы

- Последнее фото с двумя комбиками вместе убрать с текущего места и сохранить
  только как резервное.
- Второй компьютер должен передать недостающие фотографии с указанием года и
  модели: MKE 120/60, 602 PA, 1202 PA, E12 и, при наличии, N1202C для 1996.

## Ограничение этого коммита

Этот коммит фиксирует только согласованные требования. Код страницы, тексты и
фотографии сайта в нём не изменяются. Их правка начнётся после получения и
проверки недостающих материалов.
