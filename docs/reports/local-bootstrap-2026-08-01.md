# novikamps.com — результаты локального запуска

Дата: 2026-08-01

## Что сделано

- Исходники перенесены в локальный Git-репозиторий.
- Добавлен переносимый Node.js 24.18.0 и npm 11.16.0 в `.tools/` (папка игнорируется Git).
- Пересобран `package-lock.json`.
- Конфигурация ESLint переведена с устаревшего `FlatCompat` на flat config, рекомендованный для Next.js 16.

## Причина ошибки зависимостей

Исходный `package-lock.json` был внутренне несогласован: для транзитивных пакетов `@emnapi` отсутствовали записи, а версия `@emnapi/wasi-threads` не удовлетворяла требованию зависимости. Поэтому `npm ci` завершался с `EUSAGE` ещё до установки пакетов.

Исправление: lock-файл пересобран из неизменённого `package.json`, затем `npm ci` завершился успешно.

## Проверки

- `npm ci --no-audit --no-fund` — успешно, установлено 610 пакетов.
- `npm test` — успешно: 20 test files, 90 tests.
- `npm run build` — успешно: Next.js 16.1.6 собрал 35 статических страниц.

## Ошибки, которые остаются в lint

Эти ошибки были обнаружены после восстановления актуальной конфигурации ESLint. Они не исправлялись в рамках настройки локальной среды.

1. `app/actions/submit-inquiry.ts:33` — вставка в Supabase использует `as any`. Комментарий `eslint-disable` расположен строкой выше и не подавляет ошибку. Требуется сгенерировать типы базы данных или ввести явный тип DTO для строки `inquiries`.
2. `components/ds/gallery.tsx:25` — callback `onSelect()` синхронно вызывает `setSelected()` внутри `useEffect`. Правило React сообщает о риске каскадного рендера. Нужна переработка первичной синхронизации состояния Embla без синхронного setState в теле эффекта.
3. `components/inquiry/inquiry-modal.tsx:28` — `setResult(null)` синхронно вызывается в `useEffect` при изменении `open`; это та же категория риска каскадного рендера. Сброс результата нужно привязать к событию открытия или изменить модель состояния.
4. `components/product/sections.tsx:15` — импорт `Breadcrumb` не используется; его следует удалить.

Дополнительно lint выдаёт предупреждение о неиспользуемой директиве eslint в `submit-inquiry.ts` и о неиспользуемом импорте `Breadcrumb`.

## Дополнительные замечания

- Vitest сообщает предупреждение о будущей смене загрузчика конфигурации из-за ESM-синтаксиса в `vitest.config.ts`. Это не блокирует 90 проходящих тестов.
- npm просит отдельно рассмотреть install-скрипты `sharp` и `unrs-resolver`; они не были автоматически одобрены. Production build при этом прошёл.
- Для GitHub-пуша требуется подтвердить точный репозиторий сайта. Доступный приватный репозиторий `NAGHUB` — другой проект и не должен использоваться как remote для novikamps.com.

## Безопасность

В отчёт не включены `.env`, токены, ключи или production-данные. Перед любым развёртыванием нужно использовать перевыпущенные секреты из защищённого хранилища.
