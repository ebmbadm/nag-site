# Раздел «Усилители NAG» — технический макет

## Цель

Преобразовать `/catalog/amplifiers` из обычной сетки карточек в отдельную техническую страницу: флагман QM-400, его конструкция, две линейки TD и единая сравнительная таблица.

## Содержание и порядок

1. Первый экран: QM-400 как флагман, фронтальное фото на светлой подложке, короткое описание и три факта.
2. Конструктивный блок: фотография QM-400 со снятой верхней крышкой и текст о четырёх автономных каналах.
3. Две карточки серий: TD-100 / TD-80 и TD-40 / TD-30 с предоставленными фотографиями.
4. Техническая таблица: QM-400, TD-100 / TD-80 и TD-40 / TD-30; значения мощности, габаритов, массы и цены берутся из текущих MDX-карточек.

## Ограничения

- Модули TDS/TDH не включаются: это самостоятельный раздел «Модули NAG».
- Новый макет сохраняет общую шапку сайта и хлебные крошки.
- Данные моделей не дублируются вручную: компонент получает их из `qm-400.mdx` и `td-series.mdx`.
- Изображения из согласованного локального макета становятся штатными ресурсами сайта.
- Тёмная техническая поверхность сочетается со светлой подложкой только под предметными фотографиями.

## Проверка

- Тест рендерит QM-400, оба блока TD и все модели из сравнения.
- Полный Vitest и production build проходят до публикации.
