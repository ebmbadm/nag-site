# Выравнивание страницы модулей с утверждённым макетом

## Цель

Сделать `/catalog/modules` визуально соответствующей локальному варианту 02: тёмная инженерная подача, основной блок серии, два фотографических блока с практикой применения и внутренней конструкцией, затем техническая карта.

## Архитектура

Маршрут остаётся `/catalog/[slug]`, но для `modules` использует отдельный серверный компонент. Он получает существующий `ProductFrontmatter`, а не дублирует цены и характеристики: таблица и тексты используют поля MDX. Другие товарные страницы продолжают использовать общий шаблон.

## Секции

1. Флагманский hero с названием TDS / TDH, подтверждённой мощностью до 2400 Вт и фото задней панели.
2. Два блока: TDS-20 в сабвуфере и внутренняя конструкция модуля.
3. Карточки моделей из `models`.
4. Техническая таблица из `specMatrix`, документы и ссылка на общий блок характеристик.

## Ограничения

- Использовать дизайн-токены и примитивы из `components/ds`.
- Не менять общую страницу товара или другие товарные маршруты.
- Не менять проверенные значения, цены и изображения в `content/products/modules.mdx`.
