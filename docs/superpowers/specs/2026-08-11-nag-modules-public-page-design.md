# Публичная страница NAG TDS / TDH

## Цель

Обновить опубликованную карточку серии TDS / TDH на основе утверждённого локального макета: указать мощность до 2400 Вт, показать реальное применение TDS-20 в сабвуфере и внутреннюю конструкцию модуля.

## Реализация

Страница `/catalog/modules` уже строится из `content/products/modules.mdx`. Обновление остаётся в этом файле: галерея получает две новые фотографии, секция `tech` показывает внутреннюю конструкцию и объясняет практику выбора TDS-20, а матрица и карточки моделей используют 2400 Вт для TDS-20 / TDH-20.

## Ограничения

- Использовать существующие примитивы страницы товара; не вводить отдельную вёрстку.
- Изменения выполняются только в `agent/nag-modules`; `main` не редактируется напрямую.
- Утверждённое пользователем значение 2400 Вт заменяет 2200 Вт во всех видимых значениях TDS-20 / TDH-20.
- Новые изображения берутся из `public/products/modules/` и остаются локальными ресурсами сайта.
